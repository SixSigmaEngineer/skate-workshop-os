Workshop knowledge documents

This folder is Spotter's optional local workshop knowledge corpus. Add process
analysis, Gemba, Lean, Kaizen/RIE, design thinking, automation, and facilitation
reference material that you are authorized to use.

Current coverage:

- Lean and transactional process improvement
- Kaizen / Rapid Improvement Events
- Gemba, current-state and future-state process work
- IDEO-style design thinking and human-centered design
- Facilitation guides and workshop operating guides
- Knowledge graph and automation reference material

Source documents in this folder remain local and are excluded from Git. Spotter
does not replace them; it uses them as local context for the kinds of workshop
coaching SKATE should support.
