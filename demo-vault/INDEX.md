# SKATE Demo Vault

This vault contains two completely fictional nonprofit workshops for **Harborlight Community Resource Network**. Harborlight is not a real organization and no real client or participant data is included.

- Session 1: `harborlight-service-access-2026` — reducing repeated intake and invisible referrals
- Session 2: `harborlight-volunteer-readiness-2026` — improving volunteer confidence and knowledge continuity
- Entries: 25 linked memory objects across two distinct graphs
- Demonstrated types: observation, pain, quote, insight, question, opportunity, risk, recommendation, decision, and action item
- Demonstrated markers: `#O:`, `#P:`, `#Q:`, and `#A:`

The dataset is designed for judging SKATE's local-first markdown memory, session filtering, relationship graphs, workshop synthesis, tagging, and agent retrieval.
