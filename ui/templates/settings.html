Import from OneNote

Bring your Microsoft OneNote content into SKATE. Each Notebook becomes a session; each page becomes a note. First export your OneNote (in OneNote desktop: File → Export → Notebook or Section → Word Document, or use Markdown / HTML / PDF), copy the files to this computer, then point SKATE at that folder. Supported: .docx, .md, .html, .txt, and .pdf.
