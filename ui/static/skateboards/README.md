SKATE skateboard assets

Replace these files to customize the About SKATE board rails. Keep the same filenames to update the app without editing templates.

- deck-landscape.png: large branded deck at the top of the left rail.
- skate-logo-board.png: SKATE logo board.
- devpost.png: Devpost hackathon board.
- luna.png, sol.png, terra.png: GPT-5.6 model boards.
- grind.svg, local-first.svg, markdown-memory.svg, rails.svg, signals.svg, graph.svg, observe-connect.svg, session.svg: editable concept boards.

Recommended board shape: wide image, transparent or white background, about 640x180 px. New developer boards can be added here and then referenced in templates/about.html.
