# The volunteer resource directory is outdated before training ends

## Meeting notes

- #O: Eligibility rules, hours, waitlists, and contact methods change faster than the shared directory is reviewed.
- Volunteers cross-check the directory against email announcements and personal notes before giving an answer.
- Several resource entries lack an owner or last-reviewed date.
- #P: Volunteers cannot distinguish trusted guidance from stale guidance.
- #A: Add an owner, confidence level, and review date to the top 25 resources.
- #Q: Which changes should immediately mark guidance as needing review?
